## Über das Projekt / About the Project
Das **NBS** ist ein mathematisches Modul für systemkritische Rechensysteme. Durch eine neuartige mathematische Herangehensweise verhindert es strukturell das Auftreten von Nullwerten und daraus resultierenden Systemabstürzen (z.B. Division-by-Zero).

The **NBS** is a mathematical module for mission-critical systems. Using a novel mathematical approach, it structurally prevents the occurrence of zero-values and subsequent system failures.

## Systemstruktur / System Structure
Das System besteht aus 5 Komponenten / The system consists of 5 components:

1. **4 Kernmodule / Core Modules:** (ZDU, FAP, ZOB, SMH) bilden das mathematische Fundament zur strukturellen Null-Vermeidung.
2. **1 Fehlermetrik / Error Metric:** Ein dediziertes Modul zur kontinuierlichen Validierung und Überwachung der Systemintegrität.
